# FaultNet 论文指标复现 —— 训练指南

> 目标：在 FaultSeg3D 官方合成数据上，用 MD loss 分别以 γ=0.5/0.6/0.7 训练
> FaultNet，复现论文 Group-4 的 IOU 指标（**67.53 / 67.59 / 67.33**）。

## 0. 复现范围（先读）

论文分 4 组实验，**只有 Group-4（纯合成数据）能完整复现**：

| 组 | 训练数据 | 能否复现 |
|---|---|---|
| Group-1/2/3 | 合成数据 + **Shengli 油田场数据 A/B/C（未公开）** | ❌ 场数据缺失 |
| Group-4 | 纯合成数据 | ✅ **可完整复现** |

Group-4 目标指标（Fault-Net，验证 IOU%）：

| γ | IOU |
|---|---|
| 0.5 | 67.53 |
| 0.6 | 67.59 |
| 0.7 | 67.33 |

> 注：Group-4 的合成数据自带完整 3D 标签，此时 MD loss 的掩码 M 全为 1，
> 退化为「带 γ 权重的 Dice loss」。「稀疏 2D 标签」只用于 Group-1/2/3 的场数据，
> 对应功能已实现（`md_loss.build_label` / `dataset.make_sparse_label`），
> 接场数据时可直接用。

## 1. 环境

- Python 3.8 ~ 3.11（实测 3.10）
- PyTorch ≥ 2.0（实测 2.11.0+cu128；CPU 版也能跑，只是慢）
- numpy（任意较新版本；代码已避免 `np.int`/`np.single` 等已废弃别名）

```bash
pip install torch numpy          # GPU 版按显卡选：pip install torch --index-url https://download.pytorch.org/whl/cu128
```

依赖极少，只有 `torch` + `numpy`，无 scipy/opencv/segyio 依赖（训练路径不用它们）。

## 2. 数据准备

1. 下载 FaultSeg3D 官方合成数据（Google Drive，约 3.5 GB）：
   <https://drive.google.com/drive/folders/1FcykAxpqiy2NpLP1icdatrrSQgLRXLP8>

2. 解压/放置成如下结构（本目录下）：

```
data/
├── train/
│   ├── seis/     0.dat ~ 199.dat   （200 个）
│   └── fault/    0.dat ~ 199.dat   （200 个）
└── validation/
    ├── seis/     0.dat ~ 19.dat    （20 个）
    └── fault/    0.dat ~ 19.dat    （20 个）
```

每个 `.dat` 是 128×128×128 的 float32 原始数组（`np.fromfile` 直接读）。

> 下载方式：`gdown --folder "https://drive.google.com/drive/folders/1FcykAxpqiy2NpLP1icdatrrSQgLRXLP8" -O data`
> （国内网络可能慢/被阻断，建议自备代理，或从其他镜像获取同一批 200+20 个 `.dat`）。

3. 验证数据就绪：

```bash
python dataset.py data
# 期望打印：训练样本数: 200, 然后 seismic shape (1,128,128,128) 等
```

## 3. 训练

一次训练一个 γ，共跑三次：

```bash
python train_faultnet.py --gamma 0.5 --data data
python train_faultnet.py --gamma 0.6 --data data
python train_faultnet.py --gamma 0.7 --data data
```

或一键三次：

```bash
python run_all.py data
```

### 训练设置（与论文一致）

- **阶段 1**：Dice loss 预训练 200 epochs（合成数据 + 完整 3D 标签）
- **阶段 2**：MD loss(γ) 微调 200 epochs
- 优化器 Adam lr=1e-3，batch size=10，混合精度（AMP）
- 数据增强：上采样到 256³/384³ → 随机截 128³ → 随机旋转 0/90/180/270°
- 每 epoch 60 个 batch（等效 600 样本），每 10 epoch 验证一次 IOU

### 关键参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--gamma` | 0.7 | MD loss 的 γ，复现指标用 0.5/0.6/0.7 |
| `--data` | data | 数据根目录 |
| `--epochs-pre` | 200 | 阶段 1（Dice 预训练）epoch 数 |
| `--epochs` | 200 | 阶段 2（MD 微调）epoch 数 |
| `--batch-size` | 10 | 论文 batch size |
| `--val-every` | 10 | 每隔多少 epoch 验证一次 |
| `--out` | 自动 | 权重保存路径（默认 `FaultNet_Gamma{γ}.pt`） |

### 显存/时间预估

- 显存：batch=10 的 128³，AMP 下约 **6.8 GB**（8 GB 卡能跑，6 GB 卡需减 batch）。
- 速度：约 **0.6 s/step**（RTX 5070 Laptop），400 epochs = 24000 步 ≈ **4 小时/次**。
- 三次训练共约 **12 小时**。

## 4. 验证与对比

训练日志会打印 `val_IOU`。跑完后与论文目标对比：

```
γ=0.5 → 67.53   γ=0.6 → 67.59   γ=0.7 → 67.33
```

也可用训练好的权重对任意数据做推理（与官方推理脚本一致）：

```python
import torch
from network import FaultNet
m = FaultNet()
m.load_state_dict(torch.load("FaultNet_Gamma0.7.pt"))
m.eval()
# 输入 (1,1,D,H,W)，输出 (1,1,D,H,W) 的 0~1 概率
```

> 注意：本目录产出的权重是 `state_dict`（不是官方的 TorchScript `.pt`）。
> 如需 TorchScript 导出，`torch.jit.script(m)` 即可（结构已与官方一致，见下）。

## 5. 网络结构正确性（已验证）

`network.py` 是从官方 TorchScript 权重反向工程得到的**精确重建**，
`verify.py` 证明加载官方权重后前向输出逐元素一致（max diff ~1e-6）。
因此本目录训练出的模型与官方架构**完全一致**，可直接对等比较。

## 6. 常见问题

- **`AssertionError: gamma 必须在 [0.5, 1)`**：γ 取值非法（只支持 0.5/0.6/0.7）。
- **显存不足 (CUDA OOM)**：减小 `--batch-size`（如 8 或 6），或换更大的卡。
- **`FileNotFoundError: data/train/seis`**：数据目录结构不对，见第 2 节。
- **数据下载慢/失败**：Google Drive 被墙，需代理或镜像。
